# TokenBroker

### One API key. Every model you want. A network that pays you back.

**TokenBroker** is a public AI inference service: sign up, pick a model, and
query it over a standard, OpenAI-compatible API from anywhere in the world.
No GPU required. No port forwarding. No accounts on five different AI
platforms.

> **[→ Open the live service: https://tokenbroker.hopto.org](https://tokenbroker.hopto.org)**

---

## What TokenBroker is

TokenBroker brokers access to hundreds of open-weights models through a single
API. Behind the scenes, requests are fulfilled by a **distributed compute
network** — real people running a small, transparent worker application on
their own hardware — plus hosted cloud models from providers like Ollama
Cloud. You never need to know (or care) which machine answered your request;
the service masks who fulfilled it.

The result:

- **One key, one endpoint** for chat, completions, embeddings, and more.
- **Hundreds of models** — small and large, general-purpose and specialized,
  including uncensored/abliterated variants.
- **Real privacy** — your request is answered and your data is not used for
  training.
- **A community-powered network** — people contribute compute and earn
  credits; users get access to models that would never run on a laptop.

## The short pitch

**For users:** stop juggling API keys. TokenBroker gives you one account, one
key, one bill — and access to models from DeepSeek, Qwen, Gemma, GLM, Kimi,
MiniMax, Nemotron, Mistral, GPT-OSS and more, with simple transparent pricing.

**For contributors:** install the TokenBroker worker, let your GPU earn while
you sleep, and turn idle hardware into credits you can spend on API usage.

**For everyone:** no code to read, no ports to open, no data to worry about.
The whole system is designed so the machine that answers your request never
needs to know who you are.
